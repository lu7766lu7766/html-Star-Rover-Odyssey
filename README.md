# 《Star Rover Odyssey 2.0》星際巡航：互動式 JavaScript 遊戲化教學平台

版本：2.0  
語言：正體中文  
目標對象：高中普通班學生、零程式基礎  
開發技術：Vue 3 + Vite + Three.js + Pinia  
部署平台：Cloudflare Pages  
產品定位：**遊戲優先、程式概念逐步揭露**的互動式 JavaScript 探索平台

---

## 🌟 產品核心特色

1. **遊戲優先，零程式碼門檻**：
   - 不再是傳統程式碼編輯器。學生在前期透過**點擊、拖曳指令卡、調節滑桿參數、配置條件積木及迴圈次數**直接驅動 3D 遊戲世界。
   - 觀察任務 ➔ 預測結果 ➔ 操作指令 ➔ 執行遊戲 ➔ 觀察結果 ➔ 修正策略 ➔ 理解程式概念。
2. **全站亮色系視覺美學**：
   - 清爽珍珠白與淡天藍背景、白色卡片、柔和品牌藍與丁香紫點綴。
   - 3D 太空場景全面升級為明亮星雲與星球探索風格，高親和力且符合學校電腦教室友善標準。
3. **三區工作台架構 (Game Workspace)**：
   - **Zone A（3D 遊戲場景）**：佔主畫面核心，以 Three.js 呈現明亮清爽的 3D 星際探測世界。
   - **Zone B（操作區）**：指令卡拖曳排序區、滑桿參數器、條件積木等互動元件。
   - **Zone C（任務資訊區）**：任務目標、即時執行狀態、分步提示、收合式 JavaScript 語法對照碼。
4. **首頁星際地圖導航**：
   - 包含冒險起點、關卡星圖導航、學習進度條、音效開關與 JSON 存檔匯出/匯入。
5. **收合式 JavaScript 對照區**：
   - 預設收合，完成任務後展開比對，讓學生將直觀遊戲經驗自然連結至現實 JavaScript 語法。
6. **Open-Meteo 全球即時氣象 API 連線 (Level 8)**：
   - 串接真實公開天氣 API，支援逾時與離線教學模擬切換，帶領學生理解現代網路資料交換。
7. **金手指教師模式**：
   - 支援密令 `jaccis666`，可快速解鎖全部 8 個關卡，方便課堂示範與教學評量。

## 🚀 八大完整教學關卡

| 關卡 | 主題 | 核心概念 | 遊戲互動機制 | 3D 視覺反饋 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **探測船啟航** | 指令與執行順序 | 指令卡雙軌操作 (啟動引擎、前進、轉向、停止) | 探測船步進位移、轉向避開碎石並泊入發光停機坪 |
| **02** | **能源補給站** | 變數與參數 | 滑桿調節初始燃料、單次消耗、推進次數與速度 | 噴射藍色離子焰火，精準位移 24 單位並安全著陸平台 |
| **03** | **隕石避障** | 條件判斷 (if / else) | 條件積木 (< 5 煞停、< 15 減速、否則全速前進) | 雷達波即時測距，遇近距隕石自動緊急剎車避碰 |
| **04** | **水晶採集** | 迴圈與計數器 (for loop) | 迴圈次數步進調節 + 機械臂採集指令 | 機械手臂伸縮抓取，逐一採集 5 顆晶瑩能量水晶入艙 |
| **05** | **模組裝載** | 函式與物件 (Objects & Methods) | 模組選型 (量子廣角光譜儀)、屬性設定與呼叫方法 | 旋轉全息雷達天線，釋放大型環狀脈衝波顯影星體 |
| **06** | **太空艙控制中心** | 事件與 DOM (addEventListener) | 下方接線＋上方 2D 網頁親手點擊/懸停/雙擊實驗 | 2D 儀表板網頁即時改寫 textContent、style、艙門 class 滑開 |
| **07** | **無人機編隊** | 陣列與迭代 (Array forEach) | 無人機陣列清單檢視、低電量安全閾值過濾與分派 | 4 架無人機分頭出動，低電量機回塢，其餘空域巡邏 |
| **08** | **星際氣象站** | API 與外部資料 (fetch & JSON) | 選擇測站、連線 Open-Meteo API、設定安全門檻 | 氣象雷達全向旋轉，高空無人機穿破白雲升空測繪 |

## 🛠️ 本地開發與啟動

### 1. 環境需求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 2. 安裝依賴
```bash
npm install
```

### 3. 啟動開發伺服器
```bash
npm run dev
```
瀏覽終端提示之本地網址（預設 `http://localhost:5173` 或 `http://localhost:5174`）。

### 4. 執行單元測試
```bash
npm run test
```

### 5. 建置生產版本 (Production Bundle)
```bash
npm run build
```
輸出檔案位於 `dist/` 目錄，內含完整 HTML、CSS、JS 與無外部相依之純前端資源。

## ☁️ Cloudflare Pages 部署說明

本專案完全基於純靜態前端架構，100% 相容 Cloudflare Pages 靜態託管：

1. **登入 Cloudflare Dashboard** ➔ 選擇 **Workers & Pages** ➔ **Create application** ➔ **Pages** ➔ **Connect to Git**。
2. 選取本專案 Git 儲存庫。
3. **組態設定 (Build settings)**：
   - **Framework preset**：`Vite`
   - **Build command**：`npm run build`
   - **Build output directory**：`dist`
   - **Node.js Version (環境變數)**：`NODE_VERSION = 20`
4. 點擊 **Save and Deploy** 即可完成自動化 CI/CD 部署。
